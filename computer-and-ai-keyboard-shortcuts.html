1.What Is a Keyboard Shortcut?

A keyboard shortcut is a key, or a combination of keys, that runs a command in a computer program faster than using a mouse or menus. For example, to copy a sentence you could select it, open the Edit menu and click Copy. With a shortcut you select it and press Ctrl+C. The shortcut takes about a second.

Shortcuts are useful for four reasons:

  • Speed: they cut out the time spent moving the mouse and finding menu items. Over a day of work, the saved seconds add up to many minutes.
  • Comfort: using the keyboard more and the mouse less can reduce repeated reaching and clicking, and many people find it more comfortable.
  • Accessibility: people who cannot use a mouse, or who use screen readers, depend on the keyboard.
  • Focus: your hands stay in one place, so your thinking is not interrupted.

Did you know? The ideas of cut, copy and paste were developed in the 1970s at Xerox's Palo Alto Research Center, where computer scientist Larry Tesler worked on text editors. Apple's early Lisa and Macintosh computers put the X, C and V keys next to each other with the Command key, and later systems copied the pattern with the Ctrl key. This is why the same three shortcuts work almost everywhere today.

2.The Keys That Make Shortcuts Work

Most shortcuts combine a modifier key with another key. A modifier key changes the meaning of the key pressed with it. The main modifier keys are on the left side of the bottom row of the keyboard.

Ctrl (Control)The main modifier on Windows and Linux. Combined with a letter, it runs commands such as copy, paste and save.
Cmd (Command, ⌘)The main modifier on a Mac. It works like Ctrl does on Windows.

ShiftMakes capital letters and symbols, selects text when used with arrow keys, and turns many shortcuts into related ones (Ctrl+Z is undo, Ctrl+Shift+Z is redo on a Mac).
Win (Windows logo key)Opens the Start menu and starts many Windows system shortcuts.

Esc (Escape)Cancels an action, closes a menu or leaves full screen.
Enter / ReturnConfirms an action, starts a new line, or sends a message.
Delete / BackspaceRemoves characters or files. On a Mac, the key labelled Delete works like Backspace.

3.How to Read and Press a Shortcut

A shortcut such as Ctrl+C is written with plus signs, but you do not type the plus sign. It means: hold the first key (the modifier), tap the second key, then release both.

Figure 2. Pressing a two-key shortcut. The keys light up in order in the animation. (Original EDUSAMBAM diagram.)
  • "Ctrl+Shift+S" means hold Ctrl and Shift together, then tap S.
  • "Ctrl+X then Ctrl+V" means do the first shortcut, then the second.
  • Some shortcuts are single keys, such as F5 or Esc.
  • "Arrow keys" are the four keys with arrows (Up Arrow, Down Arrow, Left Arrow, Right Arrow).
  • Windows and Linux keyboards use the left-hand column of each table; Macs use the right-hand column. A dash (—) means there is no common shortcut for that system.
  • Shortcuts depend on the program and its version. If a shortcut does not work, check the program's Help or menus, where the shortcut is often shown beside the command.

Task 1: copy text from a web page into a document

Select a paragraph on a web page, copy it, switch to your document and paste it without the web page's formatting.

Press Ctrl+Home to go to the top and Ctrl+V to paste.

Task 3: research with browser tabs

Open three sources, compare them, and bring back a tab you closed by accident.

Ctrl+T opens a tab; Ctrl+L selects the address bar so that you can type a search.

Ctrl+Tab moves between tabs; Ctrl+W closes one; Ctrl+Shift+T brings it back.

26.When a Shortcut Does Not Work

  • The wrong program is active. Shortcuts work in the window that has focus. Click inside the document or page first.
  • Your laptop needs the Fn key. On many laptops the F1 to F12 keys control brightness or volume unless you hold Fn (or switch the Fn Lock setting).
  • The program uses a different shortcut. Shortcuts vary between programs and versions; look for the shortcut beside the command in the menu, or in Help.
  • Another program has claimed the shortcut. Some apps set global shortcuts. Check the app's settings or your operating system's keyboard settings.
  • A keyboard layout or language problem. If a key types the wrong symbol, check which input language is active (Win+Space).
  • A sticky or broken key. Test the key in a text box, and clean the keyboard if keys stick.
  • The shortcut is turned off by an organisation. School and work computers may block some shortcuts, such as the Task Manager.
  • Accessibility features are on. Sticky Keys or Filter Keys change how key presses behave; check the accessibility settings.

27.Using Shortcuts Safely

  • Save before you experiment (Ctrl+S) and learn Ctrl+Z (undo), which can rescue many mistakes.
  • Be careful with permanent deletion. Shift+Delete skips the Recycle Bin, so use it only when you are sure.
  • Lock the screen (Win+L, or Control+Cmd+Q on a Mac) whenever you leave a shared or public computer. Do not use "remember password" options on shared computers.
  • Do not paste unknown commands into a terminal or into your computer's Run box; some commands can damage files or install harmful software.
  • Protect private information when using AI tools. Do not paste passwords, ID numbers or other private data into a chat or a screenshot.
  • Take breaks and sit well. Shortcuts can reduce mouse use, but long typing sessions still need good posture and regular rest.

Summary

  • A keyboard shortcut runs a command with a quick key combination. It saves time, supports accessibility and helps you stay focused.
  • Most shortcuts use a modifier (Ctrl, Alt, Shift, Win on Windows; Cmd, Option, Control on a Mac) plus another key. Hold the first, tap the second, release both.
  • For most everyday shortcuts, swap Ctrl for Cmd when moving from Windows to a Mac.
  • Learn shortcuts in small groups, starting with copy, paste, undo, save and find.
  • AI chat tools have their own shortcuts, which change often; check each tool's in-app list.
  • Use shortcuts safely: save first, be careful with permanent deletion, lock shared computers and protect private data.
For teachers and parents

Try a "shortcut of the day" routine: show one shortcut at the start of each lesson and ask students to use it during the lesson. Use the practice tasks as short typing and computing activities, or time students doing the same task with and without shortcuts. Combine the topic with typing practice and good posture. Keyboards differ, so allow time for students to find the keys on their own devices, and remind them that school computers may have some shortcuts disabled. Shortcuts for AI and other web tools can change, so check the tool's help page before teaching specific ones.
