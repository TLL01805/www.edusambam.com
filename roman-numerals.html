Roman Numerals: Reading and Writing an Ancient Number System

Just seven letters and two simple rules: add or subtract. Learn to read and write any Roman numeral up to 3,999, and see where they still appear on clocks, books and sports.

Roman numerals do not use place value the way our everyday numbers do. There is no ones column or tens column. Instead, they work through just seven symbols and two clean rules for combining them. Once those two rules click, any Roman numeral becomes readable, and you can write any number up to 3,999 with confidence. This guide also shows you where Roman numerals are still used today, and why they were replaced for arithmetic.

1.What Are Roman Numerals?

Roman numerals are the number-writing system used in ancient Rome, built from combinations of just seven letters. Unlike the numbers we use every day, which rely on place value (a digit’s position changes its worth), Roman numerals work by combining symbols according to a few fixed rules.

The system is about 2,000 years old, but it never fully disappeared. It still appears on clock faces, in the credits of films and books, for numbering kings, queens and popes, in the outlines of documents and in numbering major events such as the Super Bowl.

2.The Seven Basic Symbols

Every Roman numeral, no matter how large, is built from just these seven symbols.

SymbolValue
I1
V5
X10
L50
C100
D500
M1,000

There is a neat pattern in these values. Going up the list, the value is multiplied by 5, then by 2, then by 5, then by 2 again. That is why the symbols come in a repeating “1, 5, 10” rhythm: I, V, X, then X, L, C, then C, D, M.

The circles glow in order, from I up to M.

3.Rule One: Addition

When a smaller (or equal) symbol comes after a larger one, add its value.

Example 1

VI = V (5) + I (1) = 6. XV = X (10) + V (5) = 15. LXVII = L (50) + X (10) + V (5) + I (1) + I (1) = 67.

4.Rule Two: Subtraction

When a smaller symbol comes before a larger one, subtract the smaller value from the larger one instead of adding it. This is what lets Roman numerals avoid writing the same symbol four times in a row.

Example 2

IV = V (5) − I (1) = 4. IX = X (10) − I (1) = 9. XL = L (50) − X (10) = 40. CM = M (1,000) − C (100) = 900.

Writing 4 as IIII

Adding I four times in a row looks like a reasonable way to build 4, but it breaks the standard repetition limit.

The fix: the standard modern form of 4 is IV, using the subtraction rule. IIII does still appear on many clock faces (more on that below), but in standard written use, IV is correct.

5.The Repetition Rule

A symbol can be repeated to add its value, but only up to three times in a row, and only for the symbols I, X, C and M. The symbols V, L and D are never repeated, ever.

Can Repeat (up to 3 times)Never Repeats
I, X, C, MV, L, D
Example 3

III = 3 (three I’s, allowed). XXX = 30 (three X’s, allowed). But 4 is never written as IIII in standard form, and 10 is never written as VV. Instead, the subtraction rule or a bigger symbol takes over.

6.The Subtraction Rule’s Limits

Subtraction cannot be used freely between any two symbols. A smaller symbol may only subtract from the next one or two symbols above it, never further. Only I, X and C can be used to subtract, and only one smaller symbol may be placed in front.

Smaller SymbolMay Precede (Subtract From)Gives
IV or X onlyIV = 4, IX = 9
XL or C onlyXL = 40, XC = 90
CD or M onlyCD = 400, CM = 900
V, L, DNever used to subtractVX, LC and DM are invalid
Writing 99 as IC

This looks tempting (“one before a hundred”), but I is only allowed to subtract from V or X, never from C.

The fix: 99 must be built in stages: XC (90) + IX (9) = XCIX. Each subtraction pair can only skip one size level, never jump straight from I to C.

Writing 18 as XIIX

Putting two small symbols in front of a larger one to “subtract 2” seems logical, but only one symbol may be subtracted at a time.

The fix: 18 = 10 + 5 + 3 = X + V + III = XVIII. Use addition here. Subtraction is kept for the special cases 4, 9, 40, 90, 400 and 900.

7.Writing Any Number: The Place-Value Method

Here is a method that never fails. Split the number into thousands, hundreds, tens and ones (ordinary place value), then write each part using this table, and join the pieces from left to right.

Example 4: 1994

1994 = 1,000 + 900 + 90 + 4. From the table: M, CM, XC, IV. Join them: MCMXCIV.

Example 5: 2026

2026 = 2,000 + 20 + 6 = MM + XX + VI = MMXXVI. A zero in a place (here the hundreds) is simply skipped.

Example 6: 444

444 = 400 + 40 + 4 = CD + XL + IV = CDXLIV.

Each piece lights up in turn. Break a number into thousands, hundreds, tens and ones, then convert each part.

8.Reading a Roman Numeral

To read a numeral, move from left to right. Compare each symbol with the one after it. If the next symbol is bigger, subtract the current symbol. Otherwise, add it.

Example 7: Reading MCDXCII

M (1,000) is followed by C, which is smaller, so add: +1,000. C (100) is followed by D (500), which is bigger, so subtract: −100. D (500) is followed by X, which is smaller, so add: +500. X (10) is followed by C (100), which is bigger, so subtract: −10. C (100) is followed by I, so add: +100. I (1) is followed by I, so add: +1. The last I is added: +1.

Total: 1,000 − 100 + 500 − 10 + 100 + 1 + 1 = 1,492. Grouped as pieces: M + CD + XC + II = 1,000 + 400 + 90 + 2 = 1,492. ✓

Example 8: Reading XLIX

XL = 40 and IX = 9, so XLIX = 40 + 9 = 49. Not “IL”, because I cannot subtract from L.

9.Doing Arithmetic With Roman Numerals

Because Roman numerals have no place value, adding and especially multiplying them directly is awkward. The easiest way is to convert to ordinary numbers, calculate, and convert back.

Example 9

(a) XIV + XXVII: 14 + 27 = 41 = XLI.

(b) CCLV − LXIII: 255 − 63 = 192 = CXCII.

(c) XXIV × XVII: 24 × 17 = 408 = CDVIII. Try doing that without converting! Long multiplication on Roman numerals is so hard that it is one reason the Hindu-Arabic place-value system, with its columns, eventually replaced them for calculation. Roman people did calculate, but they used counting boards and an abacus rather than writing sums.

10.A Number Roman Numerals Cannot Write: Zero

Standard Roman numerals have no symbol for zero. The Romans did not treat zero as a number the way modern mathematics does. That idea developed in India and spread from there, as covered in our Number Systems article. (A few scholars in the early Middle Ages did write the Latin word nulla, meaning “none”, in tables, but this was a word, not a numeral.)

“V, L and D can repeat, just like I, X, C and M”

Since I, X, C and M can repeat, it is easy to assume the rule applies to every symbol.

The fix: only I, X, C and M ever repeat, and never more than three times. V, L and D each appear at most once in any numeral. If you ever need “two fives”, you already have a ten (X), so V is never doubled.

11.Where Roman Numerals Are Used Today

Real-World Example

Super Bowl championships are numbered using Roman numerals. Super Bowl LVIII (58) took place in 2024. Movie sequels use them (Rocky IV), as do monarchs (Queen Elizabeth II) and the copyright years in old film credits. You will also see them on clock faces, on the cornerstones of buildings, for chapters and prefaces of books, and for the sections of a formal outline.

Many clocks write 4 as IIII (in red) instead of IV. The hand turns slowly.
Did You Know?

Many clock faces show 4 o’clock as IIII rather than IV, breaking the standard rule on purpose. Nobody knows for certain why, but one popular theory is that IIII balances visually with VIII on the opposite side of the clock face.

Did You Know?

Without extending the notation, the largest standard Roman numeral is 3,999 (MMMCMXCIX), since M can only repeat three times. To write bigger numbers, the Romans put a bar over a numeral to multiply it by 1,000, so a bar over V means 5,000. The longest numeral below 4,000 is 3,888, which is MMMDCCCLXXXVIII.

12.Common Mistakes

  • Using four in a row. IIII, XXXX and CCCC are not standard. Use IV, XL and CD.
  • Repeating V, L or D. They never repeat.
  • Subtracting the wrong pairs. IC, IL, XM and VX are invalid. Only IV, IX, XL, XC, CD and CM are allowed.
  • Subtracting more than one symbol. 18 is XVIII, not XIIX.
  • Reading left to right and always adding. In IX the I is subtracted, so IX is 9, not 11.
  • Looking for a zero. 2,005 is MMV. There is no symbol for the empty tens and hundreds.
  • Writing in the wrong order. Always go from the largest symbol to the smallest (except in the six subtraction pairs).

14.Exam-Style Questions

  1. [2 marks] Write 1,947 in Roman numerals.
  2. [2 marks] Write MCDXCII as an ordinary number.
  3. [3 marks] Work out XIV + XXVII. Give your answer in Roman numerals.
  4. [3 marks] Explain why IC is not a valid way to write 99, and write 99 correctly.
Show answers

1. 1,947 = 1,000 + 900 + 40 + 7 = M + CM + XL + VII = MCMXLVII.

2. M (1,000) + CD (400) + XC (90) + II (2) = 1,492.

3. XIV = 14 and XXVII = 27. 14 + 27 = 41 = XLI.

4. I may only be placed before V or X, so IC is invalid. 99 = 90 + 9 = XC + IX = XCIX.

15.Key Points

  • Seven symbols: I = 1, V = 5, X = 10, L = 50, C = 100, D = 500, M = 1,000.
  • A smaller symbol after a larger one is added. A smaller symbol before a larger one is subtracted.
  • I, X, C and M may repeat up to three times. V, L and D never repeat.
  • Only six subtraction pairs exist: IV, IX, XL, XC, CD and CM.
  • To write a number, split it into thousands, hundreds, tens and ones, and convert each part.
  • There is no zero, and the standard maximum is 3,999.

16.For Teachers and Parents

Learners often memorise the symbols but struggle to write numbers. The place-value table in this guide fixes that, because it connects Roman numerals to the place value they already know. Let students find real examples: clock faces, book prefaces, film credits and building dates. Ask them to write today’s year, their age and their house number. Games such as matching cards or a “Roman numeral treasure hunt” keep practice light. Point out that these numerals show how much easier our own system is for calculation, which links to Place Value & Face Value.
