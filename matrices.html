Matrices: Operations, Determinants & Transformations

From adding tables of numbers to solving equations and describing reflections and rotations, learn the whole 2 × 2 matrix toolkit with worked examples and checks.

EDUSAMBAM Editorial Team|27 min read|Last updated: November 2026|Mathematics

Every shop keeps a table of what it sells: items down the side, days across the top, numbers in the boxes. A matrix is exactly that, a rectangular grid of numbers in rows and columns, with its own rules for adding, multiplying and “dividing”. Those rules let you combine whole tables at once, solve simultaneous equations in a single line, and describe a reflection or a rotation with four numbers. This guide builds matrix arithmetic from the start and ends with the link to Transformations, where matrices become really powerful.

1.What Is a Matrix?

A matrix is a rectangular array of numbers written inside brackets. Each number is called an element (or entry). A row runs across and a column runs down. We name a matrix with a capital letter, such as A, B or M.

For example, a shop sells pens and notebooks. On Monday it sells 12 pens and 8 notebooks. On Tuesday it sells 5 pens and 9 notebooks. The sales table is the matrix 12859, where row 1 is Monday, row 2 is Tuesday, column 1 is pens and column 2 is notebooks.

Figure 1. A matrix with 2 rows and 3 columns. The gold element, 6, is in row 2, column 3.

2.Order and Special Matrices

The order of a matrix is its number of rows followed by its number of columns, written rows × columns. The matrix in Figure 1 has order 2 × 3. Say “2 by 3” and always put rows first.

  • A square matrix has the same number of rows and columns (2 × 2, 3 × 3). Most O-Level questions use 2 × 2 matrices.
  • A column vector has one column, such as 34 (order 2 × 1). A row vector has one row, such as 34 (order 1 × 2).
  • The zero matrix has every element 0. Adding it changes nothing.
  • The identity matrix I = 1001 has 1s on the main diagonal (top-left to bottom-right) and 0s elsewhere. It is explained in section 6.

Two matrices are equal only if they have the same order and every pair of matching elements is equal.

3.Adding and Subtracting Matrices

You can add or subtract two matrices only when they have the same order. Add or subtract the elements that sit in the same position.

Example 1 · Adding and subtracting

Let A = 1234 and B = 50−12.

A + B = 1+52+03+(−1)4+2 = 6226.

A − B = 1−52−03−(−1)4−2 = −4242. Take care with the double negative in the bottom-left: 3 − (−1) = 4.

Example 2 · Combining two tables

Branch X sells 12859 (rows are Monday and Tuesday, columns are pens and notebooks) and Branch Y sells 76104. The two branches together sell 12859 + 76104 = 19141513. On Tuesday, for example, the branches sold 15 pens between them.

Addition is commutative (A + B = B + A) and associative, just like ordinary addition. Subtraction is not commutative: A − B and B − A are different.

4.Multiplying a Matrix by a Number

Multiplying a matrix by a plain number (a scalar) multiplies every element by that number.

Example 3 · Scalar multiplication

(a) 3 2−314 = 6−9312.

(b) ½ 6−4108 = 3−254.

(c) If A = 3102 and B = 142−1, find 2A − B. First 2A = 6204. Then 2A − B = 6−12−40−24−(−1) = 5−2−25.

5.Multiplying Two Matrices

Matrix multiplication is not done element by element. Each element of the answer comes from one row of the first matrix and one column of the second: multiply the matching pairs and add the products.

Figure 2. The gold row of A and the red column of B combine to make the blue element in row 1, column 2 of AB.

When is multiplication possible? The number of columns of the first matrix must equal the number of rows of the second. If A has order m × n and B has order n × p, then AB exists and has order m × p. The two inside numbers must match, and the two outside numbers give the order of the answer.

Example 4 · Two 2 × 2 matrices

Let A = 1234 and B = 5678. Find AB and BA.

AB: top-left (1 × 5) + (2 × 7) = 19; top-right (1 × 6) + (2 × 8) = 22; bottom-left (3 × 5) + (4 × 7) = 43; bottom-right (3 × 6) + (4 × 8) = 50. So AB = 19224350.

BA: top-left (5 × 1) + (6 × 3) = 23; top-right (5 × 2) + (6 × 4) = 34; bottom-left (7 × 1) + (8 × 3) = 31; bottom-right (7 × 2) + (8 × 4) = 46. So BA = 23343146.

AB and BA are different. In general AB ≠ BA, so the order of multiplication must never be swapped.

Example 5 · A matrix times a column vector

Find 3−124 52. The matrix is 2 × 2 and the vector is 2 × 1, so the answer is 2 × 1.

Top: (3 × 5) + (−1 × 2) = 15 − 2 = 13. Bottom: (2 × 5) + (4 × 2) = 10 + 8 = 18. The answer is 1318.

Example 6 · Shopping bills

Two shops charge different prices (in Rs) for a notebook and a pen: Shop 1 charges Rs 30 and Rs 45, Shop 2 charges Rs 28 and Rs 50. Zara buys 4 notebooks and 3 pens. The bills are 30452850 43: Shop 1 is (30 × 4) + (45 × 3) = 120 + 135 = Rs 255 and Shop 2 is (28 × 4) + (50 × 3) = 112 + 150 = Rs 262. The answer matrix is 255262, so Shop 1 is cheaper by Rs 7.

Example 7 · Powers and a non-square product

(a) If A = 1110, then A² means A × A = 1+11+01+01+0 = 2111.

(b) Let P = 123456 (order 2 × 3) and Q = 100121 (order 3 × 2). The inside numbers match (3 and 3), so PQ exists with order 2 × 2. Top-left: 1 × 1 + 2 × 0 + 3 × 2 = 7. Top-right: 1 × 0 + 2 × 1 + 3 × 1 = 5. Bottom-left: 4 × 1 + 5 × 0 + 6 × 2 = 16. Bottom-right: 4 × 0 + 5 × 1 + 6 × 1 = 11. So PQ = 751611.

“1234 × 5678 = 5122132”

This multiplies each element by the element in the same position.

The fix: that “same position” method is not matrix multiplication. Use row times column. The top-left element is the first row of A, (1, 2), against the first column of B, (5, 7): (1 × 5) + (2 × 7) = 19, not 5. The correct product is 19224350. Say “across the first, down the second” as you work.

6.The Identity and Zero Matrices

The identity matrix I = 1001 plays the role of the number 1: for any 2 × 2 matrix A, AI = IA = A. For example 4325 1001 = 4×1+3×04×0+3×12×1+5×02×0+5×1 = 4325. The identity matrix is the only matrix for which this works for every A. The identity leaves every point where it is, so it represents “do nothing”.

The zero matrix O = 0000 plays the role of the number 0: A + O = A and AO = O.

7.The Determinant of a 2 × 2 Matrix

For the matrix A = abcd, the determinant is det A = ad − bc. Multiply the main diagonal, multiply the other diagonal, and subtract.

Example 8 · Finding determinants

(a) det 4325 = (4 × 5) − (3 × 2) = 20 − 6 = 14.

(b) det 3214 = 12 − 2 = 10.

(c) det 2412 = 4 − 4 = 0. A matrix with determinant 0 is called singular.

Example 9 · When is a matrix singular?

(a) For what value of k is k623 singular? Set the determinant to zero: 3k − 12 = 0, so k = 4.

(b) Find x if x+132x is singular. Determinant: x(x + 1) − 6 = 0, so x² + x − 6 = 0, which factorises as (x − 2)(x + 3) = 0. So x = 2 or x = −3. Check x = 2: 3322 has determinant 6 − 6 = 0 ✓.

What the determinant means

The determinant is not just a number to calculate. When a matrix transforms a shape, the area of the image is the area of the object multiplied by |det| (the size of the determinant, ignoring the sign). A negative determinant means the shape has also been flipped over, as in a reflection.

Figure 3. The matrix 3102 turns the unit square into a parallelogram with base 3 and height 2. The area becomes 6, which is the determinant 3 × 2 − 1 × 0.
Example 10 · Using the determinant for area

A shape of area 7 cm² is transformed by 4123. The determinant is 12 − 2 = 10, so the new area is 7 × 10 = 70 cm².

The enlargement matrix 3003 has determinant 9. This matches the rule from Transformations that an enlargement with scale factor 3 multiplies areas by 3² = 9. A singular matrix (determinant 0) squashes every shape flat, so its area becomes 0, and that is why it cannot be undone.

8.The Inverse of a 2 × 2 Matrix

There is no “division” of matrices, but the inverse plays the same role as a reciprocal. The inverse of A, written A⁻¹, is the matrix that satisfies AA⁻¹ = A⁻¹A = I. For A = abcd:

A⁻¹ = (1 ÷ det A) × d−b−ca

In words: swap a and d, change the signs of b and c, then divide everything by the determinant. If det A = 0 there is no inverse.

Example 11 · Finding inverses

(a) A = 4325 has det A = 14. So A⁻¹ = (1/14) 5−3−24 = 5/14−3/14−2/144/14 (the bottom-left and bottom-right can be simplified to −1/7 and 2/7).

Check: A A⁻¹ = (1/14) 4325 5−3−24 = (1/14) 20−6−12+1210−10−6+20 = (1/14) 140014 = I ✓.

(b) 2153 has det = 6 − 5 = 1, so the inverse is 3−1−52 with no fractions.

(c) 2435 has det = 10 − 12 = −2, so the inverse is (1/−2) 5−4−32 = −5/223/2−1. Dividing by a negative determinant changes every sign, so check the signs carefully.

“The inverse of 4325 is 5324”

The numbers a and d were swapped, but the signs of b and c were not changed and nothing was divided.

The fix: the inverse has three jobs: swap a and d, change the signs of b and c, and divide by the determinant. Here that gives (1/14) 5−3−24. A fast test is to multiply back. A wrong answer such as 5324 gives 26242026, which is not a multiple of the identity. Always check that A × A⁻¹ = I when you have time.

9.Solving Simultaneous Equations with Matrices

Two linear equations can be written as one matrix equation AX = B, where A holds the coefficients, X is the column of unknowns and B is the column of right-hand sides. Multiply both sides on the left by A⁻¹ to get X = A⁻¹B.

Example 12 · A first solution

Solve 2x + y = 8 and x + 3y = 9.

Step 1. Write 2113 xy = 89.

Step 2. det = 6 − 1 = 5, so the inverse is (1/5) 3−1−12.

Step 3. xy = (1/5) 3−1−12 89 = (1/5) 24−9−8+18 = (1/5) 1510 = 32.

So x = 3, y = 2. Check: 2(3) + 2 = 8 ✓ and 3 + 3(2) = 9 ✓.

Example 13 · A word problem

3 pens and 2 notebooks cost Rs 130. 5 pens and 4 notebooks cost Rs 240. Find the price of each.

Let p be the price of a pen and n the price of a notebook: 3254 pn = 130240. The determinant is 12 − 10 = 2, so the inverse is (1/2) 4−2−53.

pn = (1/2) 4×130 − 2×240−5×130 + 3×240 = (1/2) 520−480−650+720 = (1/2) 4070 = 2035.

A pen costs Rs 20 and a notebook costs Rs 35. Check: 3(20) + 2(35) = 130 ✓ and 5(20) + 4(35) = 240 ✓.

Example 14 · Negative answers, and when it fails

(a) Solve 5x + 2y = 1 and 3x + y = 1. The determinant is 5 − 6 = −1, so the inverse is (1/−1) 1−2−35 = −123−5. Then xy = −123−5 11 = −1+23−5 = 1−2. So x = 1, y = −2. Check: 5 − 4 = 1 ✓ and 3 − 2 = 1 ✓.

(b) Try x + 2y = 3 and 2x + 4y = 7. The determinant is 4 − 4 = 0, so there is no inverse. The lines are parallel (the second left-hand side is exactly double the first, but 7 is not double 3), so there is no solution. A zero determinant warns you that the equations either have no solution or infinitely many.

10.Matrices as Transformations

A 2 × 2 matrix acts on a point (x, y) written as a column vector. The result is the image point: abcd xy = ax + bycx + dy. Here is the key idea that makes it easy to find any transformation matrix:

The Column Rule

The first column of the matrix is where the point (1, 0) goes. The second column is where the point (0, 1) goes.

Check it: abcd 10 = ac, the first column, and abcd 01 = bd, the second column.

Figure 4. The matrix 2−111 sends (1, 0) to (2, 1) and (0, 1) to (−1, 1). These two image points are its two columns. The gold unit square turns into the dashed parallelogram.

Use the column rule to write down each matrix in the table. For example, a reflection in the x-axis leaves (1, 0) where it is and sends (0, 1) to (0, −1), so its columns are 10 and 0−1.

Example 15 · Applying a matrix

(a) Rotate (2, 3) by 90° anticlockwise about the origin: 0−110 23 = 0×2 + (−1)×31×2 + 0×3 = −32. This matches the rule (x, y) → (−y, x).

(b) Reflect (5, 2) in the line y = x: 0110 52 = 25. The coordinates swap.

(c) A whole shape at once. Put the three corners of the triangle (1, 1), (4, 1), (1, 3) as the columns of one 2 × 3 matrix. Then 0−110 141113 = −1−1−3141. The image corners are (−1, 1), (−1, 4) and (−3, 1), as the explorer below confirms.

Example 16 · Finding a matrix from images

A transformation sends (1, 0) to (0, −1) and (0, 1) to (−1, 0). By the column rule the matrix is 0−1−10. Its effect on (3, 2) is 0−1−10 32 = −2−3. This is the rule (x, y) → (−y, −x), so the transformation is the reflection in the line y = −x.

Limits. A 2 × 2 matrix always keeps the origin fixed, because abcd 00 = 00. So 2 × 2 matrices describe rotations and enlargements only about the origin, and reflections only in lines through the origin. A translation cannot be done with a 2 × 2 matrix, because it moves the origin.

11.Reading a Transformation from a Matrix

To identify a transformation from its matrix, read the columns as images of (1, 0) and (0, 1), then look at the determinant.

Example 17 · Identify the transformation

(a) 2002: the point (1, 0) goes to (2, 0) and (0, 1) to (0, 2). This is an enlargement, scale factor 2, centre the origin. The determinant is 4, which matches the area factor 2² = 4.

(b) 01−10: (1, 0) goes to (0, −1) and (0, 1) goes to (1, 0). This is a rotation of 90° clockwise about the origin. The determinant is 0 × 0 − (1 × −1) = 1, so the area is unchanged and the shape is not flipped.

(c) 100−1: the determinant is −1. The area is unchanged but the shape is flipped, so it is a reflection, in the x-axis. A rotation always has determinant +1, and a reflection always has determinant −1.

12.Combining Transformations and Inverses

Doing transformation P and then transformation Q means multiplying the point by P first and the result by Q. So the single matrix for “P then Q” is QP, with the second transformation written on the left. This is the opposite of the order you read it in.

Example 18 · Two reflections

Let X = 100−1 (reflection in the x-axis) and Y = −1001 (reflection in the y-axis). “X then Y” has matrix YX = −1×1+0×0−1×0+0×(−1)0×1+1×00×0+1×(−1) = −100−1, a rotation of 180° about the origin. This agrees with the combination rule from Transformations: two reflections in perpendicular lines make a half-turn.

Example 19 · The order matters

Let R = 0−110 (rotation 90° anticlockwise) and X = 100−1 (reflection in the x-axis).

R then X is XR = 1×0+0×11×(−1)+0×00×0+(−1)×10×(−1)+(−1)×0 = 0−1−10, the reflection in y = −x. It sends (2, 1) to (−1, −2).

X then R is RX = 0×1+(−1)×00×0+(−1)×(−1)1×1+0×01×0+0×(−1) = 0110, the reflection in y = x. It sends (2, 1) to (1, 2).

The two results are different transformations, so XR ≠ RX. The values (−1, −2) and (1, 2) are the same results as in Example 21 of the Transformations article.

Example 20 · The inverse undoes a transformation

R = 0−110 has determinant 0 − (−1)(1) = 1. Its inverse is (1/1) 01−10, which is the matrix for a rotation of 90° clockwise. That makes sense: turning anticlockwise and then clockwise by the same angle puts everything back. In general the inverse of a transformation matrix is the matrix of the transformation that reverses it.

“To apply P first and then Q, multiply PQ”

This reads naturally left to right, but the matrices act on the point from the left.

The fix: the point is a column vector on the right. P touches it first, so P is next to the point, and Q goes on the left: Q(P v) = (QP) v. So “P then Q” is QP. In Example 19, “R then X” was XR = 0−1−10. Test with (2, 1): R gives (−1, 2), then X gives (−1, −2), and 0−1−10 21 = −1−2 ✓. The order PQ would have given the other transformation.

13.Matrices in Real Life

  • Tables of data. Shops, schools and factories use tables of stock, marks and costs. Adding matrices combines two tables, and multiplying a price matrix by a quantity column gives total bills (Example 6).
  • Computer graphics. Moving, turning and resizing an image on a screen is calculated with matrices, because one matrix can do the work for every pixel or corner of a shape (as in Example 15c).
  • Solving many equations at once. Engineers and scientists write large systems of equations as AX = B. Computers solve them with matrix methods, and the 2 × 2 method in this article is the smallest case of the same idea.
  • Games and animation. Characters are rotated and enlarged with transformation matrices, and the inverse matrix reverses a move.
Example 21 · Marks and weights

A student has three marks, 80, 70 and 90, in tests weighted 20%, 30% and 50%. The weighted score is the row-times-column product 807090 0.20.30.5 = 80 × 0.2 + 70 × 0.3 + 90 × 0.5 = 16 + 21 + 45 = 82. Weighted averages are matrix products in disguise.

14.Common Mistakes

  • Multiplying element by element. Use row times column.
  • Assuming AB = BA. It is usually false. Keep the order given.
  • Adding matrices of different orders. They must have the same order. For multiplication, the columns of the first must equal the rows of the second.
  • Sign mistakes in the determinant. It is ad − bc, not ad + bc, and take care when b or c is negative: (−3) × 2 = −6, so subtracting it adds 6.
  • Forgetting to divide by the determinant or not changing the signs of b and c when finding an inverse.
  • Using the inverse on the wrong side. To solve AX = B use X = A⁻¹B, with A⁻¹ on the left.
  • Combining transformations in the wrong order. “P then Q” is QP.
  • Trying to use a 2 × 2 matrix for a translation, or for a rotation about a point that is not the origin.

17.Key Points

  • A matrix is a grid of numbers. Its order is rows × columns.
  • Add or subtract only matrices of the same order, element by element. A scalar multiplies every element.
  • Matrix multiplication is row times column. It needs (columns of the first) = (rows of the second), and AB ≠ BA in general.
  • For A = abcd: det A = ad − bc, and A⁻¹ = (1/det A) d−b−ca. If det A = 0 there is no inverse.
  • AX = B is solved by X = A⁻¹B.
  • Columns of a transformation matrix are the images of (1, 0) and (0, 1). The area scale factor is |det|.
  • “P then Q” is the matrix QP. The inverse matrix reverses the transformation.

18.For Teachers and Parents

Start with tables the learner already knows (a bus timetable, prices from two shops) before introducing the brackets. When teaching multiplication, have learners cover all but one row and one column with two pieces of card, so they see which numbers pair up. For transformation matrices, the column rule is far easier to remember than a table of matrices: ask “where does (1, 0) go, and where does (0, 1) go?” and let the learner write the two answers as columns. Insist on a quick check (multiply A by A⁻¹, or substitute into the original equations), because sign errors are the commonest loss of marks.
