Spreadsheets and Documents: Everyday Computer Skills

Documents and spreadsheets are used in almost every school and workplace. Learn the main ideas, the key formulas and good habits, with worked examples you can try on any computer, tablet or phone.

EDUSAMBAM Editorial Team | 19 min read | Computer

Almost every office, school, shop and small business uses two kinds of computer program every day: a program for documents, such as letters, reports and forms, and a program for spreadsheets, such as budgets, marks lists and records. Knowing how to use them well is one of the most practical skills you can have. It saves hours of work, reduces mistakes, and is listed in a very large number of job advertisements. This guide explains both kinds of program in plain language, with worked examples that you can try on a computer, a tablet or a phone, using whichever program you have.

Key Takeaways

In a spreadsheet, put one fact in each cell, begin formulas with an equals sign, and use cell references instead of typing numbers again. In a document, use heading styles and templates instead of changing each line by hand. In both, save often with clear file names, keep a backup, and check your work before you share it.

1.The Programs You Can Use

Several programs do the same jobs. The skills in this article apply to all of them, because they use the same ideas and very similar menus.

JobCommon programsTypical file types
Documents (word processing)Microsoft Word, Google Docs, LibreOffice Writer.docx, .odt, .pdf
SpreadsheetsMicrosoft Excel, Google Sheets, LibreOffice Calc.xlsx, .ods, .csv
PresentationsPowerPoint, Google Slides, LibreOffice Impress.pptx, .odp

Some of these programs are free and work in a web browser or on a phone. Others are installed on a computer. If you want to understand what the computer is doing behind the scenes, read our article on how computers work, and for online storage see our guide to cloud computing.

2.Before You Start: Basic Skills and Shortcuts

A few basic actions are used constantly in every program. Learning their keyboard shortcuts can make you much faster. On a Mac computer, use the Command key instead of Ctrl.

ActionShortcut
CopyCtrl + C
Cut (move)Ctrl + X
PasteCtrl + V
UndoCtrl + Z
RedoCtrl + Y
SaveCtrl + S
Select everythingCtrl + A
FindCtrl + F
Bold, Italic, UnderlineCtrl + B, Ctrl + I, Ctrl + U

The most valuable habit of all is to save early and save often. Many programs save automatically online, but you should never rely on that alone for important work.

3.Spreadsheets: The Main Ideas

A spreadsheet is a grid of boxes that can store text and numbers and can calculate with them. Its great strength is that when you change one number, every calculation that depends on it updates automatically. Learn these words first:

TermMeaning
WorkbookThe whole file, which may contain several sheets
Worksheet (sheet)One page of the grid, shown as a tab at the bottom
CellOne box in the grid
Column / RowColumns run up and down and are named with letters (A, B, C); rows run across and are named with numbers (1, 2, 3)
Cell addressThe name of a cell: its column letter and row number, such as C4
RangeA group of cells, written with a colon, such as A1:A5 (cells A1 to A5)
FormulaA calculation, always starting with an equals sign (=)
FunctionA built-in formula with a name, such as SUM

4.Entering Data Correctly

The quality of a spreadsheet depends on how the data is entered. Follow these rules from the start, and every later step becomes easier.

  • One fact per cell. Do not write "Ali, 45" in one cell. Put the name in one column and the marks in another.
  • A clear header row. Put a short title at the top of each column, such as "Name" and "Marks".
  • No blank rows or columns inside your data table, because they confuse sorting, filtering and charts.
  • The same format in each column. Do not mix numbers and words like "ten" in the same column.
  • Do not merge cells inside your data table. Merged cells make sorting and formulas difficult.
  • Keep units in the header, such as "Weight (kg)", so that the cells contain only numbers.

5.Formulas and Functions

Every formula starts with =. You can use the symbols + (add), - (subtract), * (multiply) and / (divide). The important rule is to use cell references instead of typing the numbers again. For example, write =B2*C2 instead of =5*20. Then, when a number in B2 or C2 changes, the answer changes by itself.

A function does a bigger job with a short name. The most useful functions for beginners are shown below, using the numbers 12, 18, 25, 10 and 35 in cells A1 to A5.

FunctionWhat it doesResult for A1:A5
=SUM(A1:A5)Adds the values100
=AVERAGE(A1:A5)Finds the mean20
=MAX(A1:A5)Finds the largest value35
=MIN(A1:A5)Finds the smallest value10
=COUNT(A1:A5)Counts the cells that contain numbers5

The AVERAGE function finds the same mean that you can learn about in our article on mean, median and mode. Spreadsheets also have functions such as MEDIAN for the middle value.

Making decisions with IF

The IF function chooses between two results. Its shape is =IF(test, result if true, result if false). Suppose a pass mark is 50 and a student's marks are in cell B2. The formula =IF(B2>=50,"Pass","Fail") shows "Pass" when the marks are 50 or more, and "Fail" otherwise. If B2 contains 45, the answer is "Fail".

Relative and absolute references

When you copy a formula to another cell, the references usually move with it. This is called a relative reference. If you copy =B2*C2 down one row, it becomes =B3*C3, which is exactly what you want in a list. Sometimes you need a reference to stay fixed, such as a single tax rate or exchange rate in cell F1. A dollar sign before the column and row, as in $F$1, makes it an absolute reference that does not move when copied.

6.A Worked Example: A Simple Monthly Budget

Here is a small budget. The monthly income of 1,200 is in cell B1, and the expenses are in cells B3 to B6.

CellColumn AColumn B
Row 1Income1200
Row 2ExpenseAmount
Row 3Rent400
Row 4Food250
Row 5Transport80
Row 6Other120
Formulas and results

Total expenses: =SUM(B3:B6) gives 850.

Money left: =B1-SUM(B3:B6) gives 1200 − 850 = 350.

Share of income spent on food: =B4/B1 gives 0.2083. If you format the cell as a percentage, it shows 20.8%.

Now the spreadsheet is useful. If the rent rises to 450, change only cell B3, and the total, the amount left and the percentage all update immediately. This is the real power of a spreadsheet.

7.Formatting, Sorting and Filtering

Formatting changes how data looks without changing its value. Use number, currency, percentage and date formats so that the data is easy to read. For example, 0.2083 shown as a percentage is 20.8%.

Sorting puts rows in order, such as marks from highest to lowest or names from A to Z. Always select the whole table before sorting so that each row stays together. Filtering shows only the rows that meet a condition, for example the students who scored below 50, and hides the others without deleting them.

Use simple formatting to help the reader: bold headers, a light fill colour for the header row, borders for tables, and column widths wide enough to show the data. If you see a row of hash signs (#####) in a cell, the column is too narrow to show the number. Widen the column.

8.Charts: Showing Data Clearly

A chart turns numbers into a picture. Select your data, including the headers, then insert a chart. The chart type should match your message.

Chart typeBest forExample
Bar or column chartComparing amounts between groupsMarks of five students
Line chartShowing change over timeMonthly sales through the year
Pie chartShowing parts of one whole (use few slices)How a budget is divided

Give every chart a clear title, label the axes with units, and avoid decoration that makes it hard to read. A simple chart that people understand immediately is better than a fancy one that confuses them.

9.Common Spreadsheet Errors

Errors are normal, and they are useful clues. Learn to read the message in the cell.

MessageUsual causeFix
#DIV/0!A division by zero or by an empty cellCheck the divisor and make sure it has a value
#NAME?A misspelled function or a name the program does not recogniseCheck the spelling of the function
#REF!A reference to a cell that no longer exists, for example after deleting a columnCorrect the reference
#VALUE!The wrong type of data, such as text in a calculationCheck that the cells contain numbers
#####The column is too narrowWiden the column

To check a result, estimate it first. If the sum of five numbers around 20 comes out as 1,000, something is wrong. Also check that you did not type a number directly into a formula that should have used a cell reference.

10.Documents: Writing a Clear, Professional Page

A word processor is not just a typewriter on a screen. It can structure, format and check a document for you. The key is to use its tools instead of working by hand.

Use styles for headings and text

A style is a saved set of formatting, such as "Heading 1", "Heading 2" and "Normal". Instead of making a title bigger and bolder by hand, apply the Heading style. This gives the whole document a consistent look, lets you change the design of all headings at once, lets readers move around using the navigation pane, and allows the program to build a table of contents automatically.

Basic layout choices

FeatureGood practice
FontA plain, readable font at 11 or 12 points; no more than two fonts in a document
Line spacingUsually 1.15 to 1.5 for easy reading
MarginsEven margins on all sides, often about 2.5 cm (1 inch)
AlignmentLeft-aligned text is the easiest to read
Spacing between paragraphsUse paragraph spacing, not repeated empty lines
ListsUse the bullet and numbering buttons, not typed dashes or numbers

Useful features to learn

  • Tables for organised information, with a header row.
  • Page numbers, headers and footers for longer documents.
  • Spelling and grammar check, while remembering that it can miss correctly spelled wrong words, such as "there" and "their".
  • Find and replace to change a name or a word everywhere at once.
  • Comments and track changes so that other people can suggest edits without destroying the original.
  • Templates: ready-made layouts for letters, reports, invoices and CVs. For example, see how a CV is organised in our guide to CV and Resume Writing, and how emails are written in professional email etiquette.

Accessibility

Good documents can be used by everyone. Use heading styles so that screen-reader programs can navigate, add short descriptions (alternative text) to pictures, choose strong contrast between text and background, and avoid using colour alone to give meaning.

11.Working Together and Sharing

Online programs let several people work on the same file. When you share a file, choose the permission carefully:

PermissionWhat the person can do
ViewRead the file only
CommentRead and add comments, but not change the text
EditChange the file

Use comments and version history instead of sending many copies by email, because many copies lead to confusion about which one is correct. Share a file only with the people who need it, and do not share files that contain private information, such as identity numbers or bank details, with people who do not need them. Our article on cybersecurity basics explains good habits for passwords and safe sharing.

12.File Management and Backup

Skill with files is as important as skill with programs. Many people lose hours looking for a document they saved under an unclear name.

  • Use clear file names that say what the file is, who it is for and when, such as Budget-October-2026.xlsx or Maths-Report-Draft2.docx. Avoid names like "new1" or "final final".
  • Use folders arranged by subject, project or year, and keep the structure simple.
  • Know the file types: .docx and .xlsx are editable; .pdf keeps the layout fixed and is best for sending a final document; .csv is a plain text file of table data that almost any program can open.
  • Back up important files. A well-known guideline is the 3-2-1 rule: keep three copies of your files, on two different kinds of storage, with one copy in a different place, such as online storage.
  • Close and reopen a file after saving to check that it opens correctly.

13.Three Practice Projects

The best way to learn is to make something real. Try these three projects, increasing in difficulty.

  1. A monthly budget. List your income and expenses, add totals with SUM, calculate the amount left, and make a pie chart of your spending.
  2. A marks sheet. Enter five student names and marks, then use AVERAGE, MAX and MIN. Add an IF formula that shows "Pass" or "Fail". For example, the marks 45, 62, 78, 50 and 91 have a total of 326, a mean of 65.2, a highest mark of 91 and a lowest mark of 45, and four of the five students pass at a pass mark of 50.
  3. A one-page report. Write a short report in a word processor with a title, two headings, a bulleted list, a small table and page numbers. Save it as a PDF.

14.Common Mistakes and How to Fix Them

MistakeFix
Typing numbers into formulasUse cell references so that results update
Putting several facts in one cellUse one fact per cell, with a header row
Sorting only one columnSelect the whole table before sorting
Formatting headings by handApply heading styles
Using spaces or empty lines to move textUse alignment, indents and paragraph spacing
Not checking calculationsEstimate the answer and test with simple numbers
Unclear file names and no backupName files clearly and follow the 3-2-1 rule
Sharing with edit permission by defaultChoose the lowest permission that is needed

15.Your Everyday Computer Skills Checklist

  • I know the shortcuts for copy, paste, undo, save and find.
  • I enter spreadsheet data with one fact per cell and a clear header row.
  • I can use SUM, AVERAGE, MAX, MIN, COUNT and IF.
  • I use cell references, and I know when to use an absolute reference.
  • I can sort, filter and make a clear chart with a title and labels.
  • I use heading styles, lists and templates in documents.
  • I name files clearly, use folders and keep a backup.
  • I check my work before sharing and choose sharing permissions carefully.

Key Terms

TermMeaning
Cell addressThe name of a cell, made of its column letter and row number
RangeA group of cells, such as A1:A5
FormulaA calculation that starts with an equals sign
FunctionA built-in formula with a name, such as SUM
Relative referenceA cell reference that changes when the formula is copied
Absolute referenceA cell reference with dollar signs that stays fixed when copied
StyleA saved set of text formatting, such as Heading 1

PDFA file type that keeps the layout the same on every device
BackupAn extra copy of a file kept in case the original is lost

A Closing Thought

Documents and spreadsheets are not difficult, but they reward careful habits. Enter data in a clean structure, let formulas do the calculations, use styles to format documents, and protect your work with clear names and backups. Each skill is small, yet together they make you faster, more accurate and more employable. Choose one of the three practice projects this week, build it from start to finish, and you will learn more in an hour than in many hours of reading.
